# 日记格式参考

## 对话记录段落格式

```
- **13:40 User：用户消息内容**       ← 首尾都有**
- **13:40 AI：** AI回复内容**          ← 开头有**+空格，末尾无**
- **13:41 User：第二句用户内容**    ← 首尾都有**
- **13:41 AI：** 第二句AI回复**         ← 开头有**+空格，末尾无**
----
```

**判断方法**：
- User（用户）：`**HH:MM User：消息内容**` — 首尾都有 `**`
- AI：`**HH:MM AI：** 消息内容` — `：**` 后有空格，**内容末尾绝对不能加 `**`**

**常见错误**：
- ❌ AI 行写成 `：**内容**`（少了星号后的空格）
- ❌ AI 行写成 `：** 内容**`（末尾多了 `**`）
- ❌ User 行写成 `：** User：内容`（末尾少了 `**`）

## 话题区域格式

```
# 话题
- 话题1
- 话题2
- 话题3
```

## 附件区域格式

```
## 附件

![[附件/YYYY-MM-DD-1.jpg]]
![[附件/YYYY-MM-DD-2.jpg]]
```

## 分隔线格式

段落之间用单独一行的 `----` 分隔，前后各空一行。
