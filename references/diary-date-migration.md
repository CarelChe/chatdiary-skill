# 日记日期迁移流程（2026-06-02 验证）

## 场景

`finalize` 后用户要求："把这段记录放到昨天的日记里"。

**为什么不能直接 append**：`finalize` 已写入当日文件，recording=false，再次 `append_transcript` 会报 `not recording`。

**为什么不能直接 `move`**：涉及多文件 + 格式 + 话题同步 + tmp 清理，手动 mv 会丢结构。

## 完整流程

### 1. 确认源文件和目标文件

```bash
ls "$CHATDIARY_OBSIDIAN_DAILY_DIR/" | grep "2026-06-0[12]"
# 源: 2026-06-02.md (含刚 finalize 的对话)
# 目标: 2026-06-01 示例事件.md (用户自命名的非标准文件名)
# 或: 2026-06-01.md (标准日期文件，不一定存在)
```

**注意**：用户可能用 `YYYY-MM-DD 描述.md` 命名（非标准），按文件名匹配事件主题。

### 2. 读两个文件

```bash
cat "$CHATDIARY_OBSIDIAN_DAILY_DIR/2026-06-02.md"
cat "$CHATDIARY_OBSIDIAN_DAILY_DIR/2026-06-01 示例事件.md"
```

### 3. 构造新目标文件

保留：
- 目标文件 frontmatter
- 目标文件已有的话题（按时间顺序）
- 目标文件已有的对话记录
- 目标文件已有的附件/总结

追加（不要覆盖）：
- 源文件的话题（追加到 `# 话题` 列表）
- 源文件的对话（插入到原对话末尾、`----` 之前）
- 源文件总结如果有（追加到 `# 总结` 末尾）

时间戳处理：
- **保留源时间戳**（= 录入时刻），不改——这样日记能区分"事件发生时间"和"记录时间"
- 如果用户明确要求改成目标日某时间，按用户要求

### 4. write_file 写新目标

```python
write_file("$CHATDIARY_OBSIDIAN_DAILY_DIR/2026-06-01 示例事件.md", new_content)
```

### 5. 清空源文件（不删除）

按 CLAUDE.md 规则"不删除/覆盖文件，除非明确指示"，保留源文件结构：

```python
write_file("$CHATDIARY_OBSIDIAN_DAILY_DIR/2026-06-02.md", """---
date: 2026-06-02
week: 2026-W23
weekday: 星期二
tags:
  - 日记
---

# 话题

# 对话记录

----
## 附件
""")
```

### 6. 清理 tmp 文件

```bash
rm -f tmp/2026-06-02-1305.txt
```

下次 `start` 命令会自动清理旧 tmp，但主动清理更干净。

## 2026-06-02 实际案例

**起因**：13:05 开始的会话，用户反思昨天（6/1）的示例事件，对话录入到 6/2。

**用户要求**：搬到 6/1。

**结果**：
- 6/1 文件追加 3 段对话（13:17/13:19/13:21），话题加 1 条，总结加 3 条
- 6/2 文件清空保留结构
- tmp 删除
- 13:17 13:19 13:21 时间戳保留（=录入时刻，不是事件时刻）

## 验证

```bash
cat "$CHATDIARY_OBSIDIAN_DAILY_DIR/2026-06-02.md"
# 期望: 27 行左右（frontmatter + 空话题 + 空对话 + 空附件）

# tmp 已清
ls tmp/ | grep "2026-06-02-1305"

```
